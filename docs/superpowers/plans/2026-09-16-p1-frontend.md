# P1 前端（上传/任务/题库/详情编辑/搜索/导出）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现设计文档 §7 的 P1 前端：批量截图上传页、任务中心（轮询+重试）、题库列表（筛选分页）、题目详情（Markdown 渲染+行内编辑+软删）、全文搜索（高亮）、导出页，并 Docker 化接入 compose。

**Architecture:** SPA（react-router v6）+ TanStack Query 管理服务端状态（任务页条件轮询、mutation 后精准失效）；API 一律走相对路径 `/api`（dev 由 Vite 代理，生产由 nginx 反代，不写死地址）；组件测试用 vitest + Testing Library，全部 mock API 层，不依赖后端运行。

**Tech Stack:** React 18.3 + TypeScript 5（strict）+ Vite 5 + Ant Design 5（zh_CN）+ @tanstack/react-query 5 + ky + react-markdown/remark-gfm/rehype-highlight + vitest 2 + Testing Library；Node 20。

**Spec:** `docs/DESIGN.md` §7（前端设计）与 §6（API 契约，以后端已实现代码为准）。执行者需同时持有两份文档。

## Global Constraints

- UI 文案全部中文；`antd ConfigProvider locale={zhCN}`。
- API 前缀固定相对路径 `/api`；dev 代理 `'/api' → http://localhost:8000`。
- 后端契约（不可改动，前端照此对齐）：
  - `POST /api/ingest/images`（multipart 字段名 `files`，可多文件）→ `201 {"post_id","task_id"}`；非图片/超 20MB → 400
  - `GET /api/tasks?status&page&page_size` → `{"items":TaskOut[],"total"}`；`POST /api/tasks/{id}/retry` → TaskOut（非 failed → 409）
  - `GET /api/questions?question_type&answer_source&company&direction&q&min_confidence&page&page_size` → `{"items":QuestionOut[],"total"}`；`PATCH/DELETE /api/questions/{id}`；DELETE → 204
  - `GET /api/search?q=` → `{"items":[QuestionOut + "rank","headline"]}`，headline 含 `<em>` 高亮
  - `GET /api/export?format=md` → `text/markdown` 附件下载
- 枚举（与后端一致）：题型 `eight_legged|handwritten_code|scenario|project` ↔ 八股/手撕代码/场景设计/项目深挖；答案来源 `original(来自原帖)|ai(AI 生成)`；任务状态 `pending(排队中)|processing(处理中)|done(完成)|done_with_warnings(完成·低置信度)|failed(失败)`。
- 低置信度阈值 `0.6`（与后端 `low_confidence_threshold` 一致），低于则置信度 Tag 用 warning 色。
- 任务页轮询规则：列表存在 `pending/processing` 时每 2s 轮询，否则停止。
- 列表服务端分页：`page` 从 1 起、`page_size` 默认 20。
- 每个页面任务必须带 vitest 渲染/交互测试；测试全部 mock `api/client`，不许起真实后端。
- 后端 P1 的 `/api/export` 不支持过滤参数 → 前端只做全量导出（过滤导出记为未来增强）；`/settings` 页 P3 不做。

### 与 spec 的偏差记录（计划评审时确认）

1. spec §7 写了 `/settings` 设置页 → P3 范围，本计划不做。
2. spec §7 导出页计划带过滤条件 → 后端 P1 未实现过滤参数，前端降级为"全量导出"，过滤导出待后端支持后补。

`frontend/src/api/client.ts`：

```typescript
import ky from 'ky'
import type { Paged, Question, QuestionUpdate, SearchItem, TaskItem } from '../types'

const api = ky.create({ prefixUrl: '/api', timeout: 60_000 })

function clean(params: Record<string, unknown>) {
  return Object.fromEntries(Object.entries(params).filter(([, v]) => v !== undefined && v !== ''))
}

export async function uploadImages(files: File[]) {
  const fd = new FormData()
  files.forEach((f) => fd.append('files', f))
  return api.post('ingest/images', { body: fd }).json<{ post_id: number; task_id: number }>()
}

export async function listTasks(p: { status?: string; page?: number; pageSize?: number } = {}) {
  return api
    .get('tasks', { searchParams: clean({ status: p.status, page: p.page, page_size: p.pageSize }) })
    .json<Paged<TaskItem>>()
}

export async function retryTask(id: number) {
  return api.post(`tasks/${id}/retry`).json<TaskItem>()
}

export async function listQuestions(
  p: {
    question_type?: string
    answer_source?: string
    company?: string
    direction?: string
    q?: string
    page?: number
    pageSize?: number
  } = {},
) {
  return api
    .get('questions', {
      searchParams: clean({
        question_type: p.question_type,
        answer_source: p.answer_source,
        company: p.company,
        direction: p.direction,
        q: p.q,
        page: p.page,
        page_size: p.pageSize,
      }),
    })
    .json<Paged<Question>>()
}

export async function getQuestion(id: string | number) {
  return api.get(`questions/${id}`).json<Question>()
}

export async function updateQuestion(id: string | number, body: QuestionUpdate) {
  return api.patch(`questions/${id}`, { json: body }).json<Question>()
}

export async function deleteQuestion(id: string | number) {
  await api.delete(`questions/${id}`)
}

export async function searchQuestions(q: string) {
  const data = await api.get('search', { searchParams: { q } }).json<{ items: SearchItem[] }>()
  return data.items
}
```

```tsx
import { InboxOutlined } from '@ant-design/icons'
import { useMutation } from '@tanstack/react-query'
import { App as AntApp, Button, Card, Dragger, Typography, Upload } from 'antd'
import { useEffect, useState } from 'react'
import { useNavigate } from 'react-router-dom'
import { uploadImages } from '../api/client'

export function collectPasteFiles(files: File[]): File[] {
  return files.filter((f) => f.type.startsWith('image/'))
}

export default function IngestPage() {
  const [files, setFiles] = useState<File[]>([])
  const navigate = useNavigate()
  const { message } = AntApp.useApp()

  useEffect(() => {
    const onPaste = (e: ClipboardEvent) => {
      const imgs = collectPasteFiles(Array.from(e.clipboardData?.files ?? []))
      if (imgs.length) setFiles((prev) => [...prev, ...imgs])
    }
    window.addEventListener('paste', onPaste)
    return () => window.removeEventListener('paste', onPaste)
  }, [])

  const mutation = useMutation({
    mutationFn: uploadImages,
    onSuccess: (_data, vars) => {
      message.success(`已提交 ${vars.length} 张图片，正在处理`)
      setFiles([])
      navigate('/tasks')
    },
    onError: () => message.error('上传失败，请重试'),
  })

  return (
    <Card title="上传面经截图">
      <Typography.Paragraph type="secondary">
        支持拖拽 / 点击选择 / Ctrl+V 粘贴截图，可一次多张，提交后自动排队处理
      </Typography.Paragraph>
      <Dragger
        multiple
        accept="image/png,image/jpeg,image/webp"
        showUploadList={false}
        beforeUpload={(_, fileList) => {
          setFiles(fileList.filter((f) => f.type.startsWith('image/')))
          return false
        }}
      >
        <p className="ant-upload-drag-icon"><InboxOutlined /></p>
        <p className="ant-upload-text">点击或拖拽图片到此处</p>
        <p className="ant-upload-hint">png / jpeg / webp，单张 ≤ 20MB</p>
      </Dragger>
      <Typography.Paragraph style={{ marginTop: 16 }}>
        已选择 {files.length} 张图片
      </Typography.Paragraph>
      <Button
        type="primary"
        size="large"
        loading={mutation.isPending}
        onClick={() => {
          if (!files.length) {
            message.warning('请先添加图片')
            return
          }
          mutation.mutate(files)
        }}
      >
        开始处理
      </Button>
    </Card>
  )
}
```

```tsx
import type { QuestionUpdate } from '../types'

export default function QuestionDetailPage() {
  const { id } = useParams()
  const navigate = useNavigate()
  const queryClient = useQueryClient()
  const [form] = Form.useForm()
  const [editing, setEditing] = useState(false)

  const save = useMutation({

    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['question', id] })
      queryClient.invalidateQueries({ queryKey: ['questions'] })
      setEditing(false)
    },
  })
  const remove = useMutation({
    mutationFn: () => deleteQuestion(id!),
    onSuccess: () => navigate('/questions'),
  })

  const startEdit = () => {

            <Button onClick={() => setEditing(false)}>取消</Button>
          </Space>
        ) : (
          <Space>
            <Button type="primary" onClick={startEdit}>编辑</Button>
            <Popconfirm title="确认删除该题目？" onConfirm={() => remove.mutate()}>
              <Button danger>删除</Button>
            </Popconfirm>
          </Space>
```

`frontend/src/pages/SearchPage.tsx`：

```tsx
import { useQuery } from '@tanstack/react-query'
import { Card, Empty, Input, List, Tag, Typography } from 'antd'
import { useState } from 'react'
import { useNavigate } from 'react-router-dom'
import { searchQuestions } from '../api/client'
import { ANSWER_SOURCE_META, QUESTION_TYPE_LABELS } from '../constants'

export default function SearchPage() {
  const [input, setInput] = useState('')
  const [submitted, setSubmitted] = useState('')
  const navigate = useNavigate()

  const { data, isFetching } = useQuery({
    queryKey: ['search', submitted],
    queryFn: () => searchQuestions(submitted),
    enabled: submitted.trim().length > 0,
  })

  return (
    <Card title="全文搜索">
      <form onSubmit={(e) => { e.preventDefault(); setSubmitted(input.trim()) }}>
        <Input.Search
          enterButton size="large" placeholder="搜索题干 / 答案 / 公司"
          value={input} onChange={(e) => setInput(e.target.value)} loading={isFetching}
        />
      </form>
      <div style={{ marginTop: 16 }}>
        {!submitted.trim() ? (
          <Empty description="输入关键词开始搜索（支持中文分词）" />
        ) : (
          <List
            dataSource={data ?? []}
            renderItem={(item) => (
              <List.Item
                style={{ cursor: 'pointer' }}
                data-result-id={item.id}
                onClick={() => navigate(`/questions/${item.id}`)}
              >
                <List.Item.Meta
                  title={
                    <span dangerouslySetInnerHTML={{ __html: item.headline }} />
                  }
                  description={
                    <Space wrap>
                      <Tag>{QUESTION_TYPE_LABELS[item.question_type]}</Tag>
                      {item.company && <Tag>{item.company}</Tag>}
                      <Tag color={ANSWER_SOURCE_META[item.answer_source].color}>
                        {ANSWER_SOURCE_META[item.answer_source].label}
                      </Tag>
                      <Typography.Text type="secondary">相关度 {item.rank.toFixed(3)}</Typography.Text>
                    </Space>
                  }
                />
              </List.Item>
            )}
          />
        )}
      </div>
    </Card>
  )
}
```

> 安全说明：`headline` 来自后端 `ts_headline`，`<em>` 是我们注入的唯一标签，其余内容由 PG 转义——自用工具风险可接受；若以后开放多用户需改为解析后渲染。
